# Листівка для Лізи — інструкція

## Структура
```
/index.html
/style.css
/script.js
/assets/
  /lisa-photos/     — фото Лізи (тільки lisa-main.jpg, для конверта)
  /gdragon-photos/  — фото Джійона (заглушки вже покладені, заміни на свої)
  /decor/           — конверт, ромашка, ведмеді, фото-сюрприз з подарунка
```

## Зміни в цій версії
- Галерею-колаж з фотографіями Лізи (колишній Етап 4) повністю прибрано:
  тепер після чату одразу відбувається перехід до подарунка.
- В подарунку тепер фото "тінумікі" (`assets/decor/tinumiki.png`).
- Поруч з коробкою подарунка стоять два ведмеді (`assets/decor/bear.png`),
  розвернуті один ліворуч, інший праворуч, обидва "дивляться" на подарунок.
- На етапі подарунка ромашки з тла плавно зникають (не накладаються на сцену
  з ведмедями і коробкою).
- Кнопки ("ТИЦЯЙ СЮДИ" і стрілка в чаті) отримали новий, більш оригінальний
  вигляд: градієнт, що переливається при наведенні, і кнопка-конверт
  з пульсуючим сердечком.

## Що вже готово (твої фінальні assets)
- `assets/decor/envelope-closed.png` / `envelope-open.png` — конверт
- `assets/decor/daisy.png` — ромашка

Це вже фінальні картинки, нічого міняти не треба, якщо все влаштовує.

## Що потрібно замінити

### 1. Фото Лізи
`assets/lisa-photos/`:
- `lisa-main.jpg` — фото на листівці в конверті (Етап 2)
- `lisa1.jpg` … `lisa8.jpg` — фото для колажу (Етап 4)

### 2. Фото Джійона
`assets/gdragon-photos/`:
- `gdragon-avatar.jpg` — маленьке фото-аватар контакту "сладусік"
- `gdragon-kiss.jpg` — фото, де він посилає поцілунок (у чаті)

### 3. Фото-сюрприз з подарунка (Етап 6)
`assets/decor/gift-photo.png` — коли подарунок відкривається, коробка
щезає і з'являється це фото. Файл ОБОВʼЯЗКОВО має бути PNG з прозорим
фоном (вирізане фото, без білого прямокутника навколо) — інакше буде
видно квадратну рамку.

### 4. Текст привітання
`script.js`, змінна на самому початку:
```js
const GREETING_TEXT = `...`;
```

### 5. Повідомлення в чаті
`script.js`, трохи нижче:
```js
const CHAT_MESSAGES = [ "...", "..." ];
```
Це приклад-заглушка — заміни на свої фрази.

### 6. Написи на фото в колажі
Масив `LISA_COLLAGE_PHOTOS` у `script.js` — можна змінити/прибрати `tag`
для кожного фото ("beautiful", "♡", "✨" тощо, або `null` — без напису).

### 7. Кольори
Усі кольори зібрані на початку `style.css` у блоці `:root`.

## Як переглянути
Відкрий `index.html` у браузері (подвійний клік), або через розширення
Live Server у VS Code. Backend не потрібен.
